## Why

`pixi update` was unsolvable on main:

```
Because singlem==0.21.4 depends on tqdm==4.67.3 and tqdm==4.70.0, we can

```

`admin/requirements.txt` was committed with the pins generated during the v0.21.3 release, and `pyproject.toml` feeds that file to setuptools as `[project].dependencies`. So the editable local package demanded `tqdm==4.67.3` while the fresh conda solve wanted 4.70.0. `.gitignore` already says this file is "tracked as a stub"; it is now actually a stub again. The pinned version is still generated by `admin/build_dep_defs_from_pixi.py` locally at release time and in CI before the wheel build.
