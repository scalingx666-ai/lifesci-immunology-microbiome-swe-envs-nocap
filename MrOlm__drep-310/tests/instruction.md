# Issue

**Title:** Publish to PyPI automatically when a version bump merges

## Description

## Summary

Adds `.github/workflows/publish.yml`, which publishes dRep to PyPI whenever a merged PR bumps `drep/VERSION`.

- **Trigger:** runs after the **Tests** workflow succeeds on a push to `master`. A failing test run never publishes. It can also be run by hand from the Actions tab.
- **Version check:** reads `drep/VERSION` and asks PyPI whether that version already exists. If it does, the workflow stops. So merges that don't bump the version do nothing.
- **Publish:** builds the sdist and wheel, runs `twine check`, and uploads with [PyPI trusted publishing](https://docs.pypi.org/trusted-publishers/). No API token is stored in the repo.
- **Release:** tags `vX.Y.Z` and creates a GitHub release with the built files attached. The release notes are that version's section of `CHANGELOG.md`.

## One-time setup needed before merging

On PyPI, go to **drep → Manage → Publishing → Add a new publisher → GitHub**. Enter owner `MrOlm`, repository `drep`, workflow `publish.yml`, environment `pypi`. Until this is in place, the upload step will fail with an authentication error.
